Guia para Leigos

Explicação simples do que cada porta significa e como funcionam ataques

Como usar: Clique em qualquer porta abaixo para ver se ela está segura ou vulnerável, e como um invasor poderia atacá-la.

Porta 21 - FTP

Transferência de Arquivos

Clique para testar

FTP é como um "correio" para enviar arquivos entre computadores. Se não protegido, qualquer pessoa na rede pode baixar, alterar ou deletar seus arquivos.

Porta 22 - SSH

Acesso Remoto Seguro

Clique para testar

SSH é como uma "chave mestra" que permite controlar o computador de longe. Se a senha for fraca, o invasor assume seu servidor inteiro.

Porta 80 - HTTP

Site na Web (sem criptografia)

Clique para testar

HTTP é como enviar um cartão postal - qualquer pessoa que interceptar a mensagem pode ler tudo. Senhas, dados pessoais, tudo fica exposto.

Porta 443 - HTTPS

Site na Web (com criptografia)

Clique para testar

HTTPS é como enviar uma carta dentro de um cofre - mesmo que alguém intercepte, não consegue ler. É o padrão seguro para sites.

Porta 445 - SMB

Compartilhamento de Arquivos em Rede

Clique para testar

SMB é como uma "prateleira compartilhada" na rede. Se vulnerável, o invasor pode colocar vírus, roubar arquivos ou sequestrar o sistema inteiro.

Porta 3306 - MySQL

Banco de Dados

Clique para testar

MySQL é onde ficam guardados todos os dados: senhas, e-mails, informações de clientes. Se aberto, o invasor pode roubar ou apagar tudo.

Porta 8080 - Proxy

Servidor Intermediário

Clique para testar

Proxy é como um "porteiro" que controla quem acessa a internet. Se aberto sem autenticação, qualquer pessoa pode usar sua rede para atividades ilegais.

Porta 8443 - Admin Panel

Painel de Administração

Clique para testar

Painel admin é como o "escritório do diretor" - quem entra controla tudo. Se a senha for fraca, o invasor vira o dono do sistema.

Teste a Força da Sua Senha WiFi

Digite sua senha WiFi atual para verificar se ela é segura. Não enviamos nada para a internet - tudo é processado localmente.

Tipos de Criptografia WiFi

WEP

INSEGURO

Criptografia antiga de 1999. Pode ser quebrada em minutos com ferramentas gratuitas.

Tempo para quebrar: 5-10 minutos

Ferramenta: aircrack-ng

Recomendação: Desativar imediatamente

Como funciona o ataque: O invasor captura pacotes e usa estatística para descobrir a chave. Com 40.000 pacotes, a senha é revelada.

WPA (TKIP)

VULNERÁVEL

Melhoria do WEP, mas ainda tem falhas conhecidas. Pode ser quebrado com ataques de dicionário.

Tempo para quebrar: Horas a dias (depende da senha)

Ferramenta: aircrack-ng + hashcat

Recomendação: Atualizar para WPA2

Como funciona o ataque: O invasor captura o "handshake" (aperto de mão) e testa senhas de um dicionário offline. Se a senha for fraca, é descoberta.

WPA2 (AES)

SEGURO*

Padrão atual. Seguro se a senha for forte (12+ caracteres). Vulnerável a ataques de dicionário se senha for fraca.

Tempo para quebrar: Anos (com senha forte)

Ferramenta: aircrack-ng + GPU potente

Recomendação: Usar senha com 16+ caracteres

Vulnerabilidade KRACK (2017): Falha no protocolo permitia interceptação. Corrigido em atualizações. Mantenha seus dispositivos atualizados.

WPA3 (SAE)

MUITO SEGURO

Mais recente e seguro. Protegido contra ataques de dicionário mesmo com senha fraca.

Tempo para quebrar: Praticamente impossível

Ferramenta: Nenhuma conhecida

Recomendação: Usar sempre que possível

Vantagens: Proteção contra Dragonblood, handshake seguro mesmo com senha fraca, criptografia mais forte.

Como Funciona um Ataque WiFi (Educação)

1

Captura de Tráfego

O invasor coloca o adaptador WiFi em "modo monitor" para capturar todos os pacotes de rede. Ele não precisa estar conectado à rede - só precisa estar no alcance do sinal.

2

Interceptação do Handshake

Quando um dispositivo se conecta à rede, ele troca dados com o roteador (handshake). O invasor captura esse momento para obter a "prova" de que tem a senha.

3

Ataque de Dicionário

Com o handshake capturado, o invasor testa milhares de senhas de um dicionário (rockyou.txt tem 14 milhões de senhas). Se a sua senha estiver na lista, é descoberta.

4

Resultado

Se a senha for fraca, o invasor a descobre em minutos/horas. Pode então acessar sua rede, roubar dados, usar sua internet para atividades ilegais, ou instalar malware.

Como Criar Senhas WiFi Fortes

FAÇA ISSO:

  • Use 16+ caracteres
  • Misture letras, números e símbolos
  • Use frases de memória (ex: "MeuCarro2024&Tem4Pneus!")
  • Use gerenciador de senhas (Bitwarden, KeePass)
  • Troque a senha a cada 6 meses

NÃO FAÇA ISSO:

  • Use senhas como "12345678" ou "senha123"
  • Use dados pessoais (nome, nascimento, placa)
  • Use a mesma senha em vários lugares
  • Use senhas curtas (menos de 12 caracteres)
  • Anote em post-its ou papel
