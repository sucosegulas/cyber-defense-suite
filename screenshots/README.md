## Como Capturar

1. Execute o servidor:
   ```bash
   python -m uvicorn app:app --reload --port 8000
   ```

2. Abra http://localhost:8000

3. Navegue por cada aba

4. Pressione `F12` → `Ctrl+Shift+P` → `Capture screenshot`

5. Ou use ferramentas como:
   - [ShareX](https://getsharex.com/) (Windows)
   - [Flameshot](https://flameshot.org/) (Linux)
   - [Snipping Tool](Windows)

## Tamanho Recomendado

- **Largura:** 1200px
- **Altura:** 800px
- **Formato:** PNG
- **Compressão:** Optimizilla ou TinyPNG
